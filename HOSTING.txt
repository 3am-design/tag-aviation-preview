TAG AVIATION — WEBSITE PREVIEW

HOST THE WEBSITE

Upload the contents of dist/ to any static HTTP/HTTPS host.
Both domain-root and subfolder hosting are supported.
No server-side routing rules or Node.js runtime are required.
Open the hosted URL to view the two design options and their page links.

EDIT AND BUILD

Use Node.js 22.12 or later.
Run npm ci, then npm run dev for local development.
Run npm run build to regenerate dist/ after editing the source.
